# Matrix_Backup_louder

🗂️ **Backup automatico dei mondi di Minecraft Java Edition**  
Un semplice script Python per salvare in modo sicuro i tuoi mondi Minecraft con un solo clic.

## 🚀 Cos'è Matrix_Backup_louder?

Matrix_Backup_louder è uno script scritto in Python che automatizza il processo di backup dei mondi di Minecraft Java Edition. Ogni volta che lo esegui, crea una copia completa della cartella `saves` con un nome basato su data e ora, così non rischi mai di perdere i tuoi progressi.

## 🧠 Requisiti

- ✅ Minecraft **Java Edition**
- ✅ Python **3.13** (o versioni compatibili)
- ✅ Sistema operativo **Windows**
- ✅ Java installato (necessario per giocare a Minecraft Java)

## 📥 Installazione

1. Scarica Python da [python.org](https://www.python.org) oppure dal Microsoft Store.
2. Clona o scarica questo repository:

oppure clicca su **Code > Download ZIP** e estrai i file.
3. Apri la cartella e fai doppio clic su `matrix.py`.

## 🧾 Come funziona

Lo script:
- Rileva la cartella dei mondi Minecraft (`.minecraft\saves`)
- Crea una cartella di backup con nome tipo `backup_2025-09-29_13-30-00`
- Copia tutti i mondi nella cartella di destinazione
- Mostra un messaggio di successo o errore

## 🔒 Sicurezza

Lo script è open source e leggibile. Non installa nulla, non modifica file di sistema, e non accede a internet. È pensato per essere semplice e sicuro.

## 📌 Note

- Funziona **solo con Minecraft Java Edition**
- Non compatibile con Minecraft Bedrock (ma può essere adattato)
- Puoi pianificare l’esecuzione automatica usando l’Utilità di pianificazione di Windows
